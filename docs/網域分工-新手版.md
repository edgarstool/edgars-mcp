# 網域分工（新手版）

## 一句話記住

| 你要做的事 | 用哪個網址 |
|-----------|-----------|
| Linear / GitHub / Agent 事件進站 | **hooks.edgars.tools** |
| ChatGPT / Cursor 連 MCP、Linear OAuth | **mcp.edgars.tools** |
| 狀態頁 | **status.edgars.tools** |

## 誰是誰

| 網域 | 背後角色 | 誰會呼叫 | 典型路徑 | Current 規則 |
|------|-----------|---------|---------|-------------|
| **mcp.edgars.tools** | EDGAR MCP / OAuth gateway | ChatGPT、Cursor、其他 MCP client | `/mcp`、`/linear/oauth/*` | MCP / OAuth authority |
| **hooks.edgars.tools** | EDGAR Event Portal | Linear、GitHub、其他 webhook/event source | `/webhooks/linear` 等 | 唯一 canonical public event ingress |
| **status.edgars.tools** | 狀態 / health surface | 人與監控 | `/`、health/status routes | 只呈現經驗證狀態 |

## Event Portal 原則

```
外部事件
  → https://hooks.edgars.tools
  → 驗簽 / normalize / dedupe
  → durable event receipt
  → async fan-out
  → Hermes / OpenClaw / 其他 bounded worker
```

Hermes、OpenClaw、linear-orchestrator 或任何 host-local webhook port 都是 downstream executor / subscriber，不是另一個公共 webhook authority。

**沒有 durable receipt 就不得成功 ACK。**

## Linear 委派

Linear webhook 的 canonical public URL：

`https://hooks.edgars.tools/webhooks/linear`

實際 production reachability、簽章、D1 receipt 與 downstream execution 必須 live verify；source config 或歷史成功紀錄不等於現在已通。

## 不再做的事

- 不建立舊產品網域 alias。
- 不保留第二套 `webhooks.*` 公共入口當 fallback。
- 不把本機 / VPS 的 agent port 直接當 webhook authority。
- 不因舊 README、Git history 或 agent memory 自動恢復 retired hostname。
